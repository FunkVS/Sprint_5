# Selenium Web autotests

Автотесты для сайта https://qa-desk.stand.praktikum-services.ru/

## Структура проекта

- `locators/` - локаторы элементов
- `pages/` - Page Object модели
- `tests/` - тестовые сценарии
- `data.py` - вспомогательные функции
- `conftest.py` - фикстуры pytest

## Автотесты
- Регистрация пользователя
- Регистрация с невалидным email
- Регистрация существующего пользователя
- Авторизация пользователя
- Разлогинивание пользователя
- Создание объявления авторизованным пользователем
- Создание объявления неавторизованным пользователем
